# ARAN OS — ERP مجموعه آران

سامانهٔ یکپارچه برای مدیریت عملیات مجموعه‌های ورزشی، اقامتی، تفریحی و رستورانی امیر مهذب‌نیا.

## امکانات نسخهٔ اولیه

- داشبورد مدیریتی با شاخص‌های رزرو، فروش رستوران و هشدار موجودی
- ثبت رزرو برای زمین‌های تنیس، تنیس ساحلی، پدل، اقامت و سایر فضاها
- مدیریت ۲۵ واحد اقامتی: ۱۷ سوئیت سه‌نفره، ۲ سوئیت چهارنفره و ۶ کلبهٔ سوئیسی
- ثبت سفارش‌های رستوران و کافی‌شاپ بیانکو
- تعریف مسیر عملیاتی بیانکو: خرید، انبار خشک و سرد، آماده‌سازی، آشپزخانه‌های سنتی/فرنگی/آسیایی، سالن و صندوق
- ثبت ورود، خروج، ضایعات و اصلاح موجودی انبار
- ساختار چندسازمانی؛ قابل استفاده برای تمام مجموعه‌های آینده
- احراز هویت، سطح دسترسی و PostgreSQL با Supabase
- کنترل دسترسی سطح ردیف (RLS) برای جداسازی داده‌های هر سازمان

## اجرای محلی

۱. فایل‌ها را در یک پوشه با ساختار زیر قرار دهید:

```text
aran-os-erp/
├── app/
│   ├── (erp)/
│   ├── login/
│   ├── actions.ts
│   ├── globals.css
│   ├── layout.tsx
│   └── page.tsx
├── lib/
│   ├── queries.ts
│   └── supabase/
├── supabase/
│   └── schema.sql
├── middleware.ts
├── package.json
└── .env.local
```

۲. در Supabase یک پروژه ایجاد کنید.

۳. محتوای فایل `supabase-schema.sql` را در **SQL Editor** همان پروژه اجرا کنید.

۴. از بخش **Authentication → Users** یک کاربر ایمیل/گذرواژه بسازید.

۵. فایل `env.example.txt` را با نام `.env.local` ذخیره و مقادیر زیر را از مسیر **Project Settings → API** در Supabase وارد کنید:

```env
NEXT_PUBLIC_SUPABASE_URL=https://YOUR-PROJECT.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

۶. وابستگی‌ها را نصب و پروژه را اجرا کنید:

```bash
npm install
npm run dev
```

۷. سامانه روی آدرس زیر باز می‌شود:

```text
http://localhost:3000
```

## استقرار روی Vercel

۱. پروژه را در GitHub قرار دهید.  
۲. در Vercel گزینهٔ **Add New Project** را انتخاب و مخزن را متصل کنید.  
۳. دو متغیر محیطی `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY` را در Vercel ثبت کنید.  
۴. Deploy را بزنید.

## نقشهٔ توسعهٔ پیشنهادی

### فاز اول: تکمیل بهره‌برداری روزانه
- تقویم گرافیکی روزانه و هفتگی رزروها
- کنترل تداخل رزرو زمین و اقامت
- چک‌این/چک‌اوت سوئیت‌ها و کلبه‌ها
- صدور رسید، پرداخت نقدی/کارت‌خوان و بدهکاران
- تعریف تعرفه‌های ساعات پیک و غیرپیک

### فاز دوم: رستوران بیانکو
- منوی دیجیتال، ثبت آیتم سفارش و ارسال به Kitchen Display
- دستور پخت و محاسبهٔ بهای تمام‌شدهٔ هر غذا
- کسر خودکار مواد اولیه از انبار
- مدیریت شیفت صندوق و مغایرت صندوق
- کنترل ضایعات، سفارش خرید و تأمین‌کنندگان

### فاز سوم: منابع انسانی و مدیریت باشگاه
- پرسنل، شیفت، حضور و غیاب و کارانه
- پروندهٔ اعضا، اشتراک و کیف پول مشتری
- مدیریت مربیان و کلاس‌های گروهی
- باشگاه مشتریان، پیامک و کد تخفیف
- گزارش سود و زیان به تفکیک بخش و مجموعه

### فاز چهارم: هوشمندسازی
- پیش‌بینی تقاضای رزرو بر اساس روز، ساعت و فصل
- هشدار هوشمند خرید مواد اولیه
- تحلیل سودآوری زمین‌ها، اقامت و بیانکو
- داشبورد مالک برای مقایسهٔ تمام مجموعه‌ها
- اتصال به کارت‌خوان، حسابداری و سامانه پیامکی
